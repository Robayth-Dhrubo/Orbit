# Orbit Domain & API Layer (Historical Source — Issue #7)

This directory contains the original controller, route, and domain service implementations from [Issue #7](https://github.com/Robayth-Dhrubo/Orbit/issues/7) (PR #11).

> [!NOTE]
> During Phase 2 integration, these modules were connected to the live database and authentication layers and are mounted at runtime from **`apps/api/src/team-api/`**. 
> 
> The active, executable backend lives in **`apps/api/`**. This folder is preserved to retain contributor commit history and standalone unit test compatibility.
